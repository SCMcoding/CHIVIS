00 / FROM ARPANET TO THE WEB · 1969–2026

Internet & Web History

A separate, sourced timeline from ARPANET through modern websites. Select a milestone to read the historical explanation; visit Time Machine to inspect preserved websites.

Before websites existed, ARPANET linked research computers in 1969 and helped establish ideas and technologies that influenced the Internet. The World Wide Web emerged separately at CERN in 1989–1990, bringing linked documents and browsers to an existing network infrastructure. Websites later evolved into graphic publications, portals, interactive services, responsive layouts, and applications.

These periods overlap. No one visual style defined an entire year, and new standards often took years to become widely used. Select a date below to explore its historical context and what changed on screen.

AN IMPORTANT DISTINCTIONThe Internet and the World Wide Web are not the same thing. The Internet is the underlying network; the Web is a system of linked resources accessed with browsers and web technologies. Tim Berners-Lee proposed the Web in March 1989; its first browser, server, and website were operating by December 1990. He announced the software to a wider Internet audience in August 1991.
