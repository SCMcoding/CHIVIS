About the specimens — No single archive can contain every typeface ever made. This growing catalog includes hundreds of historical lettering traditions, named typeface families, and digital designs, organized by broad period. When an exact digital font is unavailable, the specimen uses a labeled visual approximation; it is not an image or digital file of the original typeface.
REAL TYPEFACE PREVIEWS: exact Google Fonts load when online; proprietary fonts such as Times New Roman and Arial render only when installed. Historic types without an available digital file are identified as visual stand-ins, not claimed to be the original design. The entire historical catalog stays visible. Exact fonts appear where available; historical traditions use clearly labeled modern reference styles, never identified as the original. The status on each card tells you what you are actually seeing.
